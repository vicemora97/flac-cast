# Flac Cast vX.Y.Z

Flac Cast is a local-first FLAC player with Google Cast support. This release contains native downloads for Windows, macOS, and Linux built from tag `vX.Y.Z`.

## Downloads

| Operating system | Download | Status |
| --- | --- | --- |
| Windows x64 | `Flac-Cast-Windows-x64-Setup.exe` | Unsigned until this row explicitly states that SignPath signing was verified |
| macOS Apple silicon | `Flac-Cast-macOS-arm64.dmg` | Not Developer ID signed or notarized |
| Linux x64 | `Flac-Cast-Linux-x86_64.AppImage` | Unsigned |

Each artifact has a matching `.sha256` file. Verify the checksum before running the download.
